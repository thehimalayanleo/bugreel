# One product, two entries

BugReel is one product and one codebase. The two hackathon entries evaluate different proof layers.

## GLM-5.3 Flash Lightning Hackathon

Lead with the reasoning engine:

- bounded source retrieval
- competing diagnoses
- challenger and conservative resolver
- deterministic citation grounding
- honest timeout behavior
- trusted patch and regression gate

Primary judge question: can GLM investigate a real failure quickly without turning a plausible explanation into an unsupported claim?

## The WebMCP Challenge

Lead with the collaboration interface:

- five typed `document.modelContext.registerTool` tools
- the same React actions for people and agents
- visible receipts for agent-driven state changes
- shared failure, hypothesis, citation, and verification state
- human control of the trusted regression boundary

Primary judge question: can a person and browser agent advance the same debugging investigation without brittle clicking or manual state transfer?

## Shared artifacts

- Product: BugReel
- Repository: https://github.com/thehimalayanleo/bugreel
- Deployment: one public HTTPS application
- Demo: one narrated video under three minutes that visibly proves both GLM reasoning and WebMCP collaboration

The submission descriptions should remain distinct. The GLM entry explains why the model work is non-trivial. The WebMCP entry explains why exposing typed browser tools changes the user experience.
